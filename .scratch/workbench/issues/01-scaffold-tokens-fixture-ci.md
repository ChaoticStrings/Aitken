# 01 — Scaffold, design tokens, test fixture, CI

**What to build:** A `workbench/` project that builds to one self-contained
`dist/index.html`, renders an empty themed shell (dark and light, following the
OS), has a working unit/integration/e2e test harness, ships the trimmed real
fixture plus synthetic micro-fixtures, and is checked by CI. Nothing functional
yet — but every later ticket stands on this.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**Plan sections:** §0, §1.3 (D1, D2, D13, D14, D15), §2, §8.6, §9, §12 (harness only), §11 E-13, E-48.

**Acceptance criteria**
- [ ] `workbench/package.json` with scripts `dev`, `build`, `test`, `test:e2e`, `typecheck`, `lint`; exact-pinned deps listed in Plan §9; `tsconfig` strict + `noUncheckedIndexedAccess`; `build.target = 'es2020'` (bigint).
- [ ] `npm run build` produces exactly one file `dist/index.html` (fonts and worker inlined; no network request on `file://` open — verified by Playwright with `page.on('request')` count = 0 after load).
- [ ] Shell shows a top bar with the Workbench name and an empty Library placeholder; tokens from Plan §8.6 defined for dark and light; `prefers-color-scheme: light` switches palette (e2e: emulate media, assert `--bg-0` value differs).
- [ ] `prefers-reduced-motion: reduce` sets `--dur-1/2/3` to `0ms` (unit test on computed style in happy-dom or e2e).
- [ ] `scripts/make-fixture.mjs` takes a session folder, trims to the first N seconds (default 90), translates every GPS lat/lon by a constant offset (documented in the script; not the original location), keeps only segments/tags inside the window, copies `config.json`, and writes `test/fixtures/session_trimmed_90s/`. Run it once against the uploaded session 140717 and commit the output. Also add a `session_trimmed_90s.zip` built from the same files.
- [ ] Synthetic fixtures under `test/fixtures/synthetic/` exist for: `no-gyro`, `no-gps`, `no-labels`, `no-segments`, `gaps` (one 2 s hole), `unknown-label`, `schema-v2` (sensor.csv with `schema_version=2`), `range-problems` (unpaired START, inverted pair, overlapping pair), `crlf-bom`. Each ≤ 2 s of synthetic 100 Hz data generated by a documented script `scripts/make-synthetic.mjs`.
- [ ] Vitest runs one trivial unit test and one integration test (happy-dom + `fake-indexeddb`) green; Playwright runs one desktop (1440×900) and one mobile (Pixel 7 emulation) smoke test green.
- [ ] `.github/workflows/workbench-ci.yml` runs typecheck, unit, build, e2e on changes under `workbench/**` and uploads `dist/index.html` as an artifact. Existing Android CI untouched.
- [ ] `Documentation/Core Docs/CONTEXT.md` gains the §2 terms (Source Bundle, Journal, Edit, Review Item, Clean Bundle, Simulation, Channel, Layout, Panel) in the existing style, including the `_Avoid_` lines.
- [ ] Verification note written.

**Edge cases in scope:** E-13 (confirm bigint literals compile and run under the chosen target), E-48 (file:// open works with no service worker).

**Tests to write first:** `build produces single html`, `no network requests on file open`, `light scheme applies`, `reduced motion zeroes durations`, `fixture has expected row counts` (literal counts recorded by the script into `expected/counts.json`).

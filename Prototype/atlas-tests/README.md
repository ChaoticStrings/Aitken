# Atlas tests

Real-browser tests for **Atlas**, the multi-session map mode of `Prototype/workbench.html`.
They load the actual page in Chrome, drive it with real mouse/keyboard events, and check what is
drawn on the canvas, what is stored in SQLite, and what survives a close-and-reopen.

```
cd Prototype/atlas-tests
npm install
CHROME_PATH=/path/to/chrome npm test      # CHROME_PATH optional: defaults to system Chrome
npm test -- 04 05                         # only suites 04 and 05
npm run shots                             # screenshots into /tmp/atlas-shots (design review)
```

Needs Node 20+, Chrome/Chromium, and `python3` (stdlib `sqlite3` is used as an *independent*
reader to prove the exported file is a genuine SQLite database).

| Suite | Covers |
|---|---|
| 01-formats | every recorder generation (V1.0 / V1.1 / V2 / clean bundle / future schema / BOM+CRLF / no GPS / multi-folder zip), the raw-signal peak-basis probe, dedupe + "clean replaces plain", cross-generation M equality |
| 02-interact | grouping by zoom, marked/unmarked, multi-select type filters (checked against what is *drawn*), min severity, theme + basemap, click-to-select opacity, region fly + tile warming |
| 03-paint-select | click-drag multi-select with edge auto-scroll (down, up, past the edge, paint-off), shift-click, keyboard |
| 04-persistence | refresh, full browser close/reopen, export/import fallback, independent `sqlite3` integrity check, erase |
| 05-sources | GeoJSON / WKT-CSV / pack / point imports through the mapping dialog, Overpass resolve (mocked), blue-vs-purple rules, ride evidence with direction, search, contractor focus, index |
| 06-file-db-and-review | database in a user-chosen file (real `FileSystemFileHandle` via OPFS), newer-file-wins, unlink; Review mode regression |
| 07-guards | second-tab warning, `javascript:` links and HTML in dataset fields are inert |

All "city" fixtures and contractor names are **fictional** and generated by `gen-fixtures.mjs`;
the only real data is the trimmed 90 s ride already committed under `workbench/test/fixtures`.

Not testable here (needs the live internet or a native dialog): real OSM/CARTO tiles, a real
Overpass server, Nominatim, and the OS file picker UI itself.
